# Screenshots

Put your screenshot images in this folder using these exact names so they show up
in the main README:

- `dashboard.png` — the main window (header, visa countdown, pipeline list)
- `new-application.png` — the New application editor
- `job-boards.png` — the "Search the job boards" panel
- `email-inboxes.png` — the Connect email / inboxes modal

PNG or JPG both work. If you use different names, update the links in the top-level
`README.md` to match.
